# Aquila Sync

The small app that sends your Garmin data to Aquila.

**Don't use the green Code → Download ZIP button.** It only contains this page.

Download the app from the [latest release](https://github.com/jainam077/aquila-sync/releases/latest):

- Windows 10/11: [AquilaSync-Windows.exe](https://github.com/jainam077/aquila-sync/releases/latest/download/AquilaSync-Windows.exe)
- Mac (Apple silicon): [AquilaSync-Mac.zip](https://github.com/jainam077/aquila-sync/releases/latest/download/AquilaSync-Mac.zip)

Then follow Aquila's Settings → Your watch → Garmin → Set up.
